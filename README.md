# task-crud-practice

## 概要
COACHTECH 教材 Tutorial 11-2「タスク管理APIのCRUD実装」で作成した成果物です。
タスク管理APIのCRUD操作を実装しました。

## 使用技術
- PHP 8.x
- Laravel 10.x
- REST API（CRUD）
- API Resources、FormRequest（バリデーション）

## 学んだこと
- REST APIのCRUD実装とHTTPステータスコードの使い分け
- apiResourceルートで５つのアクションを一括定義する方法
- API Resources / FormRequestによるレスポンス整形とバリデーション

## 動作確認
Postmanを使用し、各エンドポイントにリクエストを送信し、正しいステータスコードが返ってくることを確認した。
